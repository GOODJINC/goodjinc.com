Attachment Type Icons는 Obsidian에서 일반 내부 링크로 연결한 첨부파일 앞이나 뒤에 파일 유형 아이콘을 표시하는 커뮤니티 플러그인입니다. 읽기 쉬운 링크 별칭을 유지하면서도, 링크가 이미지인지 PDF인지 스프레드시트인지 바로 알아볼 수 있습니다.

아이콘은 렌더링된 링크에만 추가합니다. Markdown 원본, 파일명, 링크 별칭은 변경하지 않으며, 파일 유형을 미리 알 수 있는 임베드와 미리보기에는 아이콘을 표시하지 않습니다.

이미지, 문서, 스프레드시트, 오디오, 영상, 압축 파일 유형을 기본으로 제공하며, 유형별 아이콘과 확장자를 수정하거나 원하는 유형을 새로 추가할 수 있습니다. 특정 폴더에만 적용하는 규칙, 규칙 우선순위, 링크 텍스트 앞·뒤 아이콘 배치도 설정할 수 있습니다.

Obsidian 1.8.7 이상에서 사용할 수 있으며, 데스크톱과 모바일을 지원합니다. Obsidian 커뮤니티 플러그인에서 `Attachment Type Icons`를 검색해 설치하고 활성화하면 됩니다.
