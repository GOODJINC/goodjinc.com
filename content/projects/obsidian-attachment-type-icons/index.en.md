Attachment Type Icons is an Obsidian community plugin that shows a file-type icon before or after regular internal links to attachments. It keeps readable link aliases intact while making it immediately clear whether a link opens an image, PDF, spreadsheet, or another file type.

Icons are added only to rendered links. The plugin never changes your source Markdown, file names, or link aliases, and it skips embeds and previews where the file type is already visible.

Built-in types cover images, documents, spreadsheets, audio, video, and archives. You can edit each type's icon and extensions, add your own types, limit rules to specific folders, set matching priority, and choose whether icons appear before or after link text.

Attachment Type Icons requires Obsidian 1.8.7 or later and works on desktop and mobile. Install and enable it by searching for `Attachment Type Icons` in Obsidian's Community plugins browser.
